# Снимок CoinGecko Demo

Каталог `coins_list.json` и 20 файлов `<TICKER>.json` получены командой:

```bash
uv run python -m src.data.coingecko_download
```

В каждом файле `endpoint` и `params` задают запрос, `fetched_at` — время получения в UTC, `data` — исходный ответ API без изменения значений. Ключ не сохраняется. Цена, капитализация и совокупный объём за 24 часа номинированы в USD; временные метки — Unix milliseconds.

Этот снимок получен 2026-10-31 в 22:16–22:17 UTC. У каждой монеты 365 точек на 00:00 UTC с 2025-11-01 по 2026-10-31 и одна свежая внутридневная точка. Последняя сохранена здесь для воспроизводимости, но исключена из обработанных таблиц. Капитализация за более ранний период не загружалась: Demo ограничен последними 365 днями.

В итоговых Parquet дата на день раньше исходной полуночи, чтобы соответствовать дате открытия закрывшейся свечи Binance. Это соглашение описано в [основном README](../../../README.md#coingecko-капитализация-и-сверка-цен). Список ID — [coingecko_ids.csv](../../processed/coingecko_ids.csv), контрольные суммы исходных файлов — [coingecko_report.json](../../processed/coingecko_report.json).

Повторный запуск в том же дневном окне использует кэш, `--force` перезаписывает снимок. Для автономной сборки сохранённых данных:

```bash
uv run python -m src.data.coingecko_build
```
